# نظام محاضر الاجتماعات بالذكاء الاصطناعي

نظام ويب عربي لإنشاء محاضر اجتماعات احترافية وتصديرها Word و PDF، مع دخول بالرقم الوظيفي وكلمة المرور ولوحة لمدير النظام.

## المزايا

- دخول بالرقم الوظيفي وكلمة المرور، وتسجيل ذاتي لأي شخص (الاسم، الرقم الوظيفي، البريد، رقم التواصل، كلمة المرور).
- أول حساب يُنشأ يصبح **مدير النظام** تلقائياً.
- لوحة المدير: إنشاء مستخدم مباشرة، تعديل، إيقاف/تفعيل، تغيير كلمة المرور، حذف، ومنح صلاحية مدير.
- المظهر: اسم النظام، الشعار، اللون الأساسي، لون ونوع وحجم الخط، لون الخلفية، ورموز النظام.
- المحضر: الحضور، التاريخ واليوم، الافتتاحية، المقدمة، مراجعة توصيات الاجتماع السابق، توصيات الاجتماع، المهام الموكلة (لكل مهمة شخص معني وموعد إنجاز إلزاميان)، ثم اسم مدير الاجتماع والتاريخ والتوقيع.
- الذكاء الاصطناعي يحوّل الملاحظات الخام (مكتوبة أو بالإملاء الصوتي) إلى محضر مصاغ رسمياً.
- زر «اجتماع متابعة» ينقل توصيات المحضر السابق تلقائياً إلى قسم المراجعة.
- تصدير Word (‎.docx) و PDF وطباعة.

## التجربة الفورية (دون أي إعداد)

افتح `index.html` في المتصفح. يعمل النظام في **الوضع التجريبي**: البيانات تُحفظ على متصفحك فقط، والصياغة الذكية غير مفعلة. للتشغيل الحقيقي على الإنترنت اتبع الخطوات التالية (مجانية بالكامل، نحو 15 دقيقة).

## النشر على الإنترنت

### 1) قاعدة البيانات — Supabase (مجاني)

1. أنشئ حساباً في <https://supabase.com> ثم **New project**.
2. من **SQL Editor** الصق محتوى الملف `supabase/schema.sql` كاملاً واضغط **Run**.
3. من **Authentication ▸ Sign In / Providers ▸ Email** عطّل خيار **Confirm email** ثم احفظ (حتى يدخل المستخدم الجديد مباشرة).
4. من **Edge Functions ▸ Deploy a new function ▸ Via Editor**: سمِّ الدالة `ai` بالضبط، الصق محتوى `supabase/functions/ai/index.ts` واضغط **Deploy**.
   - إن ظهر لاحقاً خطأ 401 عند الصياغة: افتح إعدادات الدالة وعطّل **Verify JWT** (الدالة تتحقق من المستخدم بنفسها).
5. من **Project Settings ▸ API Keys / Data API** انسخ **Project URL** والمفتاح العام (**anon** أو **publishable**).

### 2) ربط الواجهة

افتح `config.js` وضع القيمتين:

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://xxxx.supabase.co",
  SUPABASE_ANON_KEY: "المفتاح العام",
};
```

> المفتاح العام آمن للنشر؛ الحماية مطبقة في قاعدة البيانات (Row Level Security). **لا تضع** مفتاح `service_role` أو `secret` في أي ملف.

### 3) الاستضافة — GitHub Pages (مجاني)

1. أنشئ مستودعاً جديداً (Public) في GitHub.
2. ارفع جميع ملفات هذا المجلد (**Add file ▸ Upload files**) بما فيها مجلد `vendor`.
3. **Settings ▸ Pages ▸ Source: Deploy from a branch ▸ Branch: main / root ▸ Save**.
4. بعد دقيقة يظهر رابط النظام بالشكل: `https://اسمك.github.io/اسم-المستودع/`

### 4) التشغيل الأول

1. افتح الرابط ▸ **إنشاء حساب** — هذا الحساب هو مدير النظام.
2. **الإدارة ▸ الذكاء الاصطناعي**: الصق مفتاح API. مفتاح Gemini المجاني من <https://aistudio.google.com/apikey>.
3. **الإدارة ▸ المظهر**: عدّل الاسم والألوان والخط والرموز.

## ملاحظات مهمة

- مشاريع Supabase المجانية تتوقف مؤقتاً بعد أسبوع دون استخدام؛ تُعاد من لوحة Supabase بضغطة.
- مفتاح الذكاء الاصطناعي يُحفظ في جدول لا يقرؤه إلا مدير النظام والخادم، ولا يصل إلى متصفحات المستخدمين.
- كل مستخدم يرى محاضره فقط؛ مدير النظام يرى الجميع.
- الدخول بالرقم الوظيفي يعتمد على دالة تُرجع البريد المرتبط بالرقم؛ أي من يعرف رقماً وظيفياً يمكنه تقنياً معرفة بريد صاحبه.
- محتوى الملاحظات يُرسل إلى مزوّد الذكاء الاصطناعي المختار لصياغته؛ راجع سياسة جهتك قبل إدخال معلومات حساسة.
- راجع دائماً ما يصوغه الذكاء الاصطناعي قبل اعتماد المحضر.
- تصدير PDF المباشر يعمل في Chrome و Edge و Firefox؛ في Safari يفتح النظام مربع الطباعة لتختار «حفظ بتنسيق PDF».

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة والتنسيق |
| `app.js` | واجهة المستخدم |
| `backend.js` | الاتصال بقاعدة البيانات / الوضع التجريبي |
| `export.js` | عرض المحضر وتصدير Word و PDF |
| `config.js` | بيانات الربط بـ Supabase |
| `vendor/` | مكتبات جاهزة (Supabase, docx, jsPDF) |
| `supabase/schema.sql` | الجداول والصلاحيات |
| `supabase/functions/ai/index.ts` | دالة الخادم للذكاء الاصطناعي وإدارة المستخدمين |
